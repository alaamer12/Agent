# Template: Executive summary (Normal mode)

```
**Bottom line:** [The one-sentence takeaway.]

[1–2 supporting paragraphs: the key reasons, evidence, or context behind
the bottom line, in descending order of importance.]

[Optional: caveats, open questions, or what would change the conclusion.]
```

Use when the reader needs the finding, the reasoning, and the recommendation, but not the full evidence. ~10% of source length. This is the default register when the user does not specify a form.
