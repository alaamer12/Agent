# Verification Checklist (run before finalizing)

- [ ] Each side was researched or inspected independently (not just one side's own framing)
- [ ] Every "advantage" passed the differentiator test
- [ ] Every claim has a stated reason it matters in practice or understanding
- [ ] Every superiority/magnitude claim is graded (green/yellow/red) and presented with matching confidence — no undisclosed-basis claim stated as flat fact
- [ ] Primary (structural, verifiable) points are visually/rhetorically distinguished from side points
- [ ] Figures, standings, or claims that can go stale are from a current search where the domain warrants it, not memory alone — and dated if they might go stale
- [ ] Any outdated or superseded claim is explicitly flagged as historical if included at all
- [ ] No absolute "X wins" claim without either a stated use case attached, or a genuine factual asymmetry backing it
- [ ] Length is proportional to genuine differences
- [ ] Local subjects (files/projects/modules) were actually read; external subjects used independent sources
- [ ] Missing resources (PDFs, key files) were requested rather than invented
- [ ] If sources were used, they are cited briefly (name + rough date), not presented as the model's own settled knowledge
