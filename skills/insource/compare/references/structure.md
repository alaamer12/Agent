# Output Structure and Length Rules

## Default structure: point-by-point

Organize by criterion/dimension, discussing all subjects inside each. This is almost always clearer than block structure (everything about A, then everything about B).

Recommended skeleton:

1. **One-paragraph framing** — what is being compared, the decision or question at stake, and (if relevant) the mode and dimensions used.
2. **A focused set of criteria sections** (typically 4–8; fewer for simple cases). Each section: the difference → why it matters → nuance or caveat if needed.
3. **A short "fits if / choose X when" section** that maps concrete situations to subjects. For purely descriptive comparisons (e.g. two biological processes), replace with "how to tell them apart" or "why the distinction matters."
4. **No padding** — no filler history lessons, no restating a table in prose afterward, no "in conclusion, both are important."

When comparing files, modules, or projects, prefer concrete evidence (paths, line counts, specific behaviors, test results) over abstract adjectives.

## Neutrality and conclusion

Avoid crowning an absolute winner except where a factual asymmetry has a real answer (e.g. one process is haploid-producing and the other isn't). For judgment calls:

- State honest trade-offs, including real weaknesses of the option that looks stronger.
- Convert the decision into "A fits if [concrete situation], B fits if [concrete situation]."
- If the user's own constraints are known, give a direct recommendation for them specifically, separate from the general case.

## Calibrate depth

Write for a curious, competent non-specialist unless context shows otherwise. Define unfamiliar terms briefly on first use; do not over-explain basics the question implies the reader already knows. Ask rather than guess when audience level would change the comparison substantially.

## Length discipline

Length must be proportional to genuine differences. A comparison with 4 real differences should not be padded into 12 rows. Prefer fewer, sharper points over exhaustive coverage of minor traits.
