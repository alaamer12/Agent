# references/

Local map for PVC skill reference docs. Load only what the task needs.

| File | Concern | Load when |
|------|---------|-----------|
| `architecture-core.md` | Conceptual model: roles, principles, benefits, Search/Modal examples, recursive composition, feature relationship | Defining or explaining what Page/View/Component/Decoration/Aligner/UI Element mean |
| `rules-and-violations.md` | Hard rules, violations, classification checklist, anti-patterns, diagnostic sentence | Reviewing, enforcing, or listing must/must-not |
| `project-structure.md` | Folders, naming, co-location, import direction, small/large app trees | Scaffolding structure or naming files |

Do not re-explain rules inside architecture-core or role theory inside project-structure. Link instead.
