# Anonymous-Run Ledger

Written by any agent before or during an anonymous run (iwts / delegated), read first on resume
(AGENTS.md section 17). One section per run; newest on top.

- Status: <in progress | handed back | done> + what remains, by file.
- Decisions made: links to `docs/decisions/<slug>.md` - never inline bodies.
- Assumptions left standing: each with its cost, flagged until the user confirms.
- Uncertainties and parked findings: what was noticed but deliberately not touched.
