# Disclaimers

The reliance instrument: what the page *isn't* (advice, a warranty, a relationship, a human). Gate
varies by content shape, and one honest rule covers all sub-types: a disclaimer **qualifies**
claims, it never cures false or unsubstantiated ones (FTC guidance), and conduct beats text — an
advising site with a "not advice" footer has written a contradiction.

## Sub-types and where each lives

1. **Informational/content (health, legal, finance blogs)** — "general information, not advice for
   your facts; consult a [professional class] before deciding". Placement: **inline box next to
   the advice-shaped claim**, not a footer relic; repeat on long pages. Add the "as at" date and
   update policy. The FDA-style "not evaluated…" string belongs to product labelling, not blog
   copy — do not borrow it for comfort.
2. **Investment / trading risk** [regulated brokers, crypto, CFDs] — prescribed wording, verbatim,
   same prominence as the dominant claim, on **every** surface incl. affiliate content: ESMA/CySEC
   CFD warning with the firm's **own** retail-loss percentage (recalculated quarterly; the 74–89%
   band only as fallback), FCA crypto line ("prepared to lose all the money you invest"). This is
   a dedicated page **and** per-promotion text — a linked paraphrase is the violation pattern.
3. **Professional-services sites** (law/medical/financial practices) — "no attorney-client /
   doctor-patient relationship forms by contacting us"; privileged-until-engagement line;
   "Attorney Advertising" where the state requires; "prior results do not guarantee similar
   outcomes" wherever results appear; responsible-attorney name + regulator/licence number.
   Dedicated page + per-page short line.
4. **General site** — AS-IS / AS-AVAILABLE with named excluded warranties; accuracy without
   promise; external links = no control, no endorsement. A footer-level paragraph usually
   suffices; courts read vague exclusions ("of whatsoever nature") against the drafter — name
   what you exclude.
5. **AI content** — synthetic-media labels where platforms/regulators require them (EU AI Act
   Art. 50 transparency; YouTube/Meta/TikTok realistic-content labels; FTC Impersonation Rule,
   live Jul 2024, bans holding content out as human). Declare the project's actual practice;
   never adopt a label to look careful about content that isn't AI.

## Ask the user - never invent

Advice-adjacency of the content; regulatory status of the operator (licence numbers are config,
never invented); which markets' prescribed texts apply; what is actually AI-generated.

## Failure patterns

Footer 8px gray as the whole strategy; one global "not advice" while the site answers user
specifics like an adviser; stale loss percentages; disclaimer substituting for substantiation;
"this site is secure" badges nobody issued.
