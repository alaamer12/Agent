# Prompt Patterns for Project Assets

Keep prompts short, positive, and purpose-driven. Front-load the subject. State style, background, lighting, and exact size/aspect when known.

## UI / Icon

```
Flat vector icon of a gear for a settings button, 512x512, transparent background,
soft indigo-to-violet gradient, clean geometric lines, centered, no text, no drop shadow
```

```
Minimalist line-art icon of a shopping cart, black stroke on transparent, 256x256,
consistent 2px stroke weight, rounded corners
```

## Product / Hero

```
Studio product photo of a matte-black wireless headphone resting on a soft blue fabric,
three-point soft lighting, shallow depth of field, 4:3, commercial advertising style
```

```
Cinematic wide shot of a modern SaaS dashboard on a laptop screen in a bright coworking space,
natural window light, shallow DOF, 16:9
```

## Illustration / Marketing

```
Isometric 3D illustration of a small team collaborating around a floating kanban board,
pastel color palette, soft ambient occlusion, clean white background, 1:1
```

```
Hand-drawn watercolor illustration of a mountain trail at sunrise, warm golden light,
loose brush strokes, 3:2, no text
```

## Placeholder / Avatar

```
Abstract geometric avatar, overlapping translucent circles in teal and coral,
512x512, flat design, centered composition
```

## Style anchors that work well

- "flat vector", "line art", "isometric 3D", "studio product photo", "cinematic wide shot"
- "transparent background", "soft gradient background", "clean white background"
- Explicit size or aspect: "512x512", "16:9", "1:1 square"
- Lighting: "soft three-point lighting", "natural window light", "dramatic rim light"

Avoid long negative lists; the models respond better to positive description.
