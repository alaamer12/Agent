# Rule table — copy this first

> One table per boundary. Fill it before writing the auditor: the rows are the rule registry, and a
> row you cannot fill is a rule you have not decided yet. Every path, name and number below is an
> illustrative placeholder.

## 1. Layer → may know → refused by → severity

| Layer | May know | Refused by | Rule code | Severity | Baseline |
| --- | --- | --- | --- | --- | --- |
| [seam file] | the vendor's name, its entry points, its internals (§4) | — (this is the one place the name lives) | — | — | — |
| [skin tier] | the seam's own names, not the vendor's | import wall + markup wall | `VENDOR_TAG_IN_MARKUP` | ratcheted | own file |
| [component layer] | the skin tier's names only | import wall | `LAYER_SKIP_TO_VENDOR` | hard-zero | none |
| [view / page layer] | component names, never primitives | markup wall | `VENDOR_TAG_IN_MARKUP` | hard-zero | none |
| [data / service layer] | nothing about the UI vendor | import wall | `VENDOR_IMPORT_OUTSIDE_SEAM` | hard-zero | none |

Two rows earn their place beyond the obvious vendor-name row: **`LAYER_SKIP_TO_VENDOR`** — a consumer
reaching past the tier that skins the vendor, straight to the raw thing, which looks completely
reasonable in review — and the skin tier's **ratcheted** row: it is legal for that tier to touch the
vendor's shape and illegal for it to leak the shape upward, which is a judgment, so it carries a count.

## 2. Severity column, decided by one question

| Could a competent reviewer disagree that this is wrong? | Severity | Baseline entry |
| --- | --- | --- |
| no — the fact is checkable | **hard-zero** | none; absent means clean |
| yes — it depends on intent | **ratcheted** | its own counts file; only growth fails; re-bless every decrease in the same change |

Ratcheting a judgment-free rule encodes the debt the wall exists to remove. Two auditors never share
one counts file.

## 3. Exemptions are data, in this table, not prose in a comment

An exemption without a reason and a row is a violation with better formatting. An exemption whose
scope matches no files is a hole nobody is using, and gets deleted by the same liveness check that
finds dead rule globs.
