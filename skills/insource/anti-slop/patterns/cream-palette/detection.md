# Detection: Cream / beige palette

## Catalog route

The official catalog classifies this as a **source** rule. Warm-neutral color matches are only candidates for product-fit review.

## Candidate signals

1. Inventory warm-neutral surfaces/accent tokens and their roles across representative pages.
2. Compare palette use with brand, audience, product content, and actual interface states.
3. Assess whether repeated neutral treatments make unrelated pages feel templated or obscure role hierarchy.
4. Measure actual text/control contrast in rendered themes and states.

## False-positive controls

- Do not flag cream, beige, tan, or muted palettes solely by hue.
- Do not assume novelty is better than brand fit.
- Do not infer accessibility from token color names; measure the rendered pair.

## Test disposition

Source candidates can find repeated warm-neutral choices, but only project comparison and visual context can assess template sameness or fit. Include a coherent intentional neutral brand palette and a generic reused template as visual calibration cases. Regex cannot confirm.
