# Among Us

Another agent is in this project. Changes you didn't make are theirs.

On trigger, acknowledge with exactly one line — `COPY That!` — then continue working under these rules, no commentary after:

1. **Don't get confused.** Unfamiliar edits are not corruption; do not panic, do not revert, do not "restore" anything you didn't touch.
2. **Re-read before editing** - adapt to the current state, keep your changes additive.
3. **Same-file collision:** wait until they finish it, or work another file and come back.
4. **Never fight the other agent.** Their edit wins over your assumption about what the file contained.
5. **Generosity with numbered identities.** Whenever agents work anonymously in any manner - shared numbered
   labels like `devXX` (branch names, commit tags, report authors, whatever scheme the project uses) - a
   number taken first is a fact, not a dispute. If the other agent already claimed the identity you intended
   (you planned `dev72`, their `dev72` landed before yours), do not contest, split, reuse, or rewrite theirs -
   be generous: apply `/dtb` judgment, shift your work to the next free number (`dev73`), and continue.
