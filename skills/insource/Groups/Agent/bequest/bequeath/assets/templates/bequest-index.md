## How to use this directory

1. Read this index first; open only the cards whose "What it does" matches the current task.
2. Open the asset's `README.md` for inputs, assumptions and verification status.
3. Run its tests before trusting it, especially when the status is `partially verified`.
4. Improve assets in place (and update their card) rather than creating a second copy.
5. At the end of a session that produced reusable work, run the `bequeath` skill to add new assets.
