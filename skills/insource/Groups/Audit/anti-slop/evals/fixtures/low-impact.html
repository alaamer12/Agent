Using saved views

Saved views help you return to a useful set of filters and columns.

Saved views are optional. Choose a name that describes the task, then select the filters and columns that help you find the information you need. You can update the view later, share it with a teammate, or return to the original settings whenever you want.

This brief note is supplemental guidance. All controls and actions remain available without reading this paragraph, and the page does not depend on this note to complete a task.
