# Template: Structured digest (Normal mode)

```
## Summary
[2–4 sentences: the overall point.]

## Key points
- [Point 1 — the most important, phrased as a claim, not a topic]
- [Point 2]
- [Point 3]

## Caveats / Open questions
[Only if material.]
```

Use for longer or multi-topic sources where the reader needs the shape of the whole argument. ~15–25% of source length.
